# Craft Atelier v0.2
スマホ向けの手芸制作・資料管理アプリです。静的HTML/CSS/JSだけで動き、データはブラウザのlocalStorageに保存します。

## v0.2
- 制作プロジェクト：作成・編集・削除、種類、ステータス、進捗、開始日、メモ
- 推しぬい設計書：全体、顔、髪、ボディ、衣装、布・刺繍糸
- 制作記録：日付＋工程メモ
- 図案・型紙ライブラリ：カテゴリ、自作/第三者、出典URL、作者、利用条件メモ
- 材料箱：種類、色、品番、在庫、メモ
- 手芸の基本図鑑：縫い方一覧→詳細→4工程の骨組み（画像は後日追加）

## 更新方法
`index.html` `style.css` `app.js` をリポジトリ直下へ上書きしてください。README.mdも任意で更新できます。

※ v0.1の簡易データを初回読み込み時に参照します。v0.2以降は `craftAtelierV2` に保存します。
