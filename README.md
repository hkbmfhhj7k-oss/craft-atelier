# Craft Atelier v0.1

スマホファーストの手芸制作・資料管理アプリの初版です。

## v0.1
- アトリエホーム
- 制作プロジェクト登録（localStorage保存）
- 図案・型紙ライブラリの入口
- 材料箱
- 手芸の基本図鑑の入口
- SVGベースのUIアイコン（外部アイコン画像不使用）

## 次に育てたいもの
- 推しぬい設計書（顔・髪・服・型紙・刺繍）
- 画像/PDF/URL資料登録と出典管理
- 材料在庫・色番号管理
- 制作工程と写真ログ
- 基本技法のオリジナル手順イラスト
- 編み図エディタ
- 編み図 → 簡易3Dプレビュー

`index.html` をブラウザで開けば動きます。GitHub Pages / Cloudflare Pagesにも載せられる静的構成です。
